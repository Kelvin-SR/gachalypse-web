# Gachalypse — página web

Página web del juego **Gachalypse** (Gachalypse Studio): portada, política de privacidad, borrado de cuenta, términos de uso y probabilidades del Altar de Invocación.

Se publica con GitHub Pages en **https://kelvin-sr.github.io/gachalypse-web/**.

No se edita aquí: la web se mantiene dentro del proyecto del juego (carpeta `web/`), donde las probabilidades se generan a partir de la configuración del juego, y se copia a este repositorio para publicarla.
